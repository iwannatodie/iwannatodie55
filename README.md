# @iwannatodie — Reveal HUD v12

## Исправление координат по IP
В v9 отсутствующие координаты из основного сервиса передавались как `null`. В JavaScript выражение `Number(null)` даёт `0`, из-за чего карточка могла показывать ложные координаты `0°, 0°`.

В v10 координаты проходят отдельную валидацию: пустые значения и `null` не превращаются в ноль, а значения вне допустимого диапазона широты/долготы отклоняются. Полная пара координат берётся из одного сервиса, чтобы не смешивать широту и долготу от разных источников. Если координаты не вернули основной и дополнительный сервисы, выполняется финальная попытка через IPAPI. Если ни один источник не даёт валидную пару, экран покажет `НЕДОСТУПНО`, а не фиктивные нули.

## Анимация и музыка
- `track.mp3` уже включён в архив; SoundCloud не требуется.
- Первый дроп начинается на `00:12.3` аудиофайла, а анимационные шаги следуют по локальной карте ударов.
- Резервная очередь продолжает раскрытие, если отдельные события пропущены или вкладка была заторможена.
- При замене `track.mp3` текущая карта ударов больше не будет соответствовать новому треку.

## Публикация на Netlify
1. Распакуйте архив.
2. Откройте папку `iwannatodie_v12`.
3. Загрузите всё содержимое папки на Netlify, включая `track.mp3`, заменив прежнюю версию.
4. После публикации убедитесь, что `https://ВАШ-САЙТ/track.mp3` открывает аудиофайл.

## Проверки в этой сборке
- `node --check app.js` проходит.
- Сценарии координат протестированы на ответах с `null`, пустыми значениями, валидными координатами, ответе резервного сервиса и полном отсутствии координат.
- Проверены уникальность HTML-ID, значения `data-step` (0–36), ссылки на локальные файлы и целостность ZIP.

## Приватность
Отчёт браузера формируется на клиенте. Запросы к IP-геосервисам передают публичный IP соответствующему сервису для ответа. Сайт не отправляет полный отчёт владельцу; Cloudflare Web Analytics используется для агрегированной статистики посещений. Координаты по IP приблизительные и не указывают точный адрес.


## Убрано описание в превью ссылок

В `index.html` title изменён на `@iwannatodie`; meta description и Open Graph/Twitter description оставлены пустыми, чтобы превью в мессенджерах не показывало текст вроде «digital trace / цифровой профиль устройства». После загрузки на Netlify мессенджер может продолжить показывать старую карточку из кэша. Для Telegram откройте @WebpageBot и отправьте ссылку на сайт, чтобы обновить страницу предпросмотра; если бот не предлагает обновление, отправьте URL с новым query-параметром, например `https://iwannatodie.netlify.app/?v=12`.

## Изменения v12
- Порог начала раскрытия установлен на 12.3 секунды аудиофайла (`DROP_AT_MS = 12300`). Обратный отсчёт, прогресс и fallback рассчитываются от этой константы.
- Отображаемый IP — публичный IP сетевого выхода, который видит используемый IP-геосервис. WebRTC не используется для обхода VPN/прокси и попыток получить скрытый исходный адрес.
